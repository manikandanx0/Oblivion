Main methods:

1. `System.out.print()`
2. `System.out.println()`
3. `System.out.printf()`
4. `String.format()`

- `print()` method
	Prints on the same line
- `println()` 
	Prints on a new line
- `printf()`
	Used for formatted output like C language
	`System.out.printf("format string", values);`


| Specifier | Meaning                   |
| --------- | ------------------------- |
| %d        | Integer                   |
| %f        | Floating point            |
| %s        | String                    |
| %c        | Character                 |
| %b        | Boolean                   |
| %n        | New Line (better than \n) |
