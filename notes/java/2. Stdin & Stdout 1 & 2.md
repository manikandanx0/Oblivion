

There are many ways to get input in Java


one popular way is by using the `Scanner class` and specifying the input stream as `System.in`

`import java.util.Scanner;`

1. Taking integer: `sc.nextInt();`
2. Taking string: sc.next();
3. Taking full sentence: sc.nextLine();


```java
Scanner sc = new Scanner(System.in);
String myString = scanner.next();
int integer = scanner.nextInt();
scanner.close();
```


### **Issues that may rise**
when using `sc.nextInt()` (or any other datatype specific sc method) it leaves a new line in the buffer so the next input may be empty
#### Fix
```java
int age = sc.nextInt();
sc.nextLine(); // clears buffer

String name = sc.nextLine();
```

```Java
import java.util.*;  

public class Solution {
	public static void main(String[] args) {
		
		Scanner scan = new Scanner(System.in);
		
		int a = scan.nextInt();
		int b = scan.nextInt();
		int c = scan.nextInt();
		
		System.out.println(a);
		System.out.println(b);
		System.out.println(c);
	
	}

}
```

```Java
import java.util.Scanner;

public class Solution {
	public static void main(String[] args) {
		Scanner scan = new Scanner(System.in);
		int i = scan.nextInt();
		double d = scan.nextDouble();
		scan.nextLine(); // clears buffer
		String s = scan.nextLine();
		
		// Write your code here.
		
		System.out.println("String: " + s);
		
		System.out.println("Double: " + d);
		
		System.out.println("Int: " + i);
	}
}
```
